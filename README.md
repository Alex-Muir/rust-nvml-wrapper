# rust-nvml-wrapper
RPM specs and srpms for Rust crates needed to package nvml-wrapper (a dependency for GNOME Resources) for Fedora.

## wrapcenum-derive
[Upstream](https://github.com/rust-nvml/wrapcenum-derive)

[Crate - wrapcenum-derive](https://crates.io/crates/wrapcenum-derive)

# Dependencies
nvml-wrapper needs nvml-wrapper-sys and wrapcenum-derive.

# What Is Included Here
This repository contains spec files and srpms for nvml-wrapper and its dependencies. Also insluded is the mock configuration generated by `copr-cli mock-config` for the `rust-nvml-wrapper` COPR project. It includes the project's repo so builds can resolve `nvml-wrapper-sys` and `wrapcenum-derive` as dependencies.

# Overall Goal
nvml-wrapper is one of many dependencies for GNOME Resources. The intention is to eventually package Resources for Fedora.
